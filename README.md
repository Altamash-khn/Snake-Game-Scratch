# Snake Game - Scratch Project

A classic Snake game made using Scratch — a block-based visual programming language developed by MIT that helps beginners learn programming concepts like logic, conditions, loops, variables, and game development in a simple and interactive way.

## About The Project
This project recreates the classic Snake game where the player controls a snake, collects food to earn points, and avoids collisions to survive as long as possible.

## Features
- Snake movement using arrow keys
- Food collection system
- Score tracking
- Collision detection
- Game over system

## Controls
| Key | Action |
|---|---|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |

## Project File
Download and open the `.sb3` file using Scratch.
